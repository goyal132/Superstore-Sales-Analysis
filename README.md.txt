Superstore Sales Data Analysis

📊 Project Overview
This project analyzes the Superstore Dataset using Microsoft Excel.  
It highlights sales, profit, and regional performance through pivot tables, charts, and an interactive dashboard.  
The goal is to derive meaningful business insights from raw data and present them in a clear and visual format.


 🔑 Key Insights
- Identified top-performing categories and sub-categories
- Analyzed profit margins by region and segment
- Highlighted underperforming regions affecting overall profitability
- Created time-based sales trends to track growth
